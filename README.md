# Hanboard Releases

Public downloads for **Hanboard** (macOS Chinese input method).

This repository holds **installer binaries only**. Application source code is maintained in a separate private repository.

## Download

See [Releases](https://github.com/BryantWork/hanboard-releases/releases/latest) for `Hanboard-Installer-Mac-*.zip`.

## Install

1. Download the latest installer zip  
2. Open `HanboardInstaller.app` and follow the prompts  
3. System Settings → Keyboard → Input Sources → add Hanboard  
4. Log out and back in if the input menu does not refresh  

Requires macOS 12.0+. Builds are Developer ID signed and notarized when published from the release pipeline.
